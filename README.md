# R²-SAFE (ต้นแบบเชิงวิจัย)

ต้นแบบเว็บของระบบช่วยตัดสินใจเลือกกลยุทธ์การบริหารความปลอดภัยสถานศึกษา บนฐานความเสี่ยงและความพร้อมขององค์กร (ประกอบดุษฎีนิพนธ์ ร่าง)

- เว็บ: https://sarawut2206.github.io/risk-safe/
- ใช้ข้อมูลจำลอง ไม่เก็บและไม่ส่งข้อมูลผู้ใช้ ประมวลผลในเบราว์เซอร์เท่านั้น
- เกณฑ์ ตารางตัดสินใจ และคลังมาตรการ 68 รายการ (SB-001 ถึง SB-068) เป็นร่าง ยังไม่ตรวจหลักฐานรายข้อ และยังไม่ผ่านเดลฟายและการประเมินโดยผู้ทรงคุณวุฒิ
- หากเกิดเหตุฉุกเฉินจริง ให้ปฏิบัติตามแผนเผชิญเหตุและกฎหมายทันที ระบบนี้ไม่ใช้แทนดุลยพินิจของผู้อำนวยการ

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css`, `app.js` | หน้าเว็บ |
| `engine.js` | เครื่องคำนวณกลไกตัดสินใจ (ย้ายจากเครื่องมือ Excel ต้นแบบ) |
| `data.js` | คลังมาตรการ ชุดการตัดสินใจ R1–R9 ข้อคำถามความเสี่ยงและ 7-S ข้อมูลตัวอย่างสมมติ |
| `bankloader.js`, `config.js` | โหลดคลังมาตรการจาก Google Sheets (อ่านอย่างเดียว) ตรวจข้อมูลก่อนใช้ ถ้าไม่ได้ใช้ข้อมูลที่ฝังไว้ |
| `apps-script/Code.gs` | โค้ด Google Apps Script (doGet อ่านอย่างเดียว) วางในโครงการ Apps Script แล้ว deploy ดูขั้นตอนในหัวไฟล์ |
| `tests/test_engine.js` | ทดสอบเทียบผลกับ Excel (`node tests/test_engine.js`) |
| `tests/test_bankloader.js` | ทดสอบตัวตรวจและตัวโหลดคลังมาตรการ (`node tests/test_bankloader.js`) |

การจัดลำดับมาตรการ (ข้อ B5): องค์ประกอบ 7-S ที่ช่องว่างสูงสุดก่อน → ลำดับ QSPM (`qpri`, ว่าง = 1) → ระดับหลักฐาน A–D (`evg`) → ลำดับในคลัง มาตรการที่เหมาะแต่เกินทรัพยากรที่มีจะแยกแสดงในรายการ "เกินทรัพยากร" ไม่ถูกตัดทิ้งเงียบ ๆ และมาตรการที่มีเงื่อนไขก่อนดำเนินการจะแสดงสถานะว่าอยู่ในรายการหรือไม่ (ไม่สลับลำดับอัตโนมัติ) ระดับหลักฐานมาจากการค้นรอบแรกเมื่อ 5 พ.ย. 2569 (แหล่งส่วนใหญ่อ่านจากบทคัดย่อ) ยังไม่ใช่การค้นเชิงระบบ

ลำดับ QSPM: ช่อง `qpri` ของมาตรการ (1–20, 1 = ดีที่สุดในประเด็นเดียวกัน, ว่าง = 1) ใช้จัดลำดับภายในกลุ่มเดียวกันตามข้อ B5 ปัจจุบันยังว่างทั้งหมด เพราะยังไม่ได้ทำเดลฟายและ QSPM (โครงอยู่ในไฟล์ R2-SAFE-QSPM-ลำดับมาตรการ-ร่าง.xlsx)

ข้อมูลใน `data.js` ควรแก้ผ่าน commit เพื่อให้มีประวัติการเปลี่ยนแปลง (เช่น แต่ละรอบเดลฟายติด tag) ห้ามนำข้อมูลโรงเรียนจริงหรือข้อมูลบุคคลเข้าที่เก็บนี้

## หน้าตาส่วนเครื่องมือ (V0.4)

ส่วนเครื่องมือประเมินปรับเป็นหน้าตาแบบแอป (มือถือก่อน) ตามต้นแบบภาพที่ผู้วิจัยจัดทำ: หน้าแรก, ข้อมูลโรงเรียนและเอกสาร, ประเมินความเสี่ยง, ประเมินความพร้อม 7-S, PNI, ตาราง R1-R9, กลยุทธ์ และแผนงาน มีแถบเมนูล่าง 5 ปุ่ม

- ไฟล์: `tool.js` (สร้าง HTML ของหน้าเครื่องมือ), `tool.css` (หน้าตา) ส่วน `engine.js` และกฎคำนวณไม่เปลี่ยน ชุดทดสอบเดิมยังผ่านทั้งหมด
- ตัวเลขทุกจุดมาจากเครื่องคำนวณและข้อมูลที่ผู้ใช้กรอกเท่านั้น ส่วนในภาพต้นแบบที่ระบบยังไม่มีข้อมูลรองรับ (กราฟแนวโน้มเหตุการณ์ ตัวชี้วัดผลลัพธ์ ปฏิทินกำหนดส่ง การดึงข้อมูลอัตโนมัติจากไฟล์ SAR) **ไม่ได้ทำเป็นตัวเลขสมมติ** แต่ใช้ข้อมูลที่มีจริงแทน
- การอัปโหลดเอกสาร: จดเฉพาะชื่อไฟล์ ขนาด และวันที่ในหน่วยความจำของเบราว์เซอร์ ไม่อ่านเนื้อหาและไม่ส่งไฟล์ไปที่ใด (หายเมื่อรีเฟรช)
- ขนาดโรงเรียนจัดจากจำนวนนักเรียนเพื่อแสดงผลเท่านั้น ยังไม่ใช้ในการคำนวณ


## กลไกตัดสินใจ การอธิบายเหตุผล วงจรเรียนรู้ และการพิสูจน์ผล (V0.6)

- `decision.js` กฎรายแกน (A1–A3, B1–B3) และกลยุทธ์เฉพาะช่อง R1–R9 ตัวบังคับกฎ (สลับมาตรการที่ไม่ตอบเงื่อนไขพร้อมบันทึกเหตุผล) ตัวอธิบายทำไมเลือก/ไม่เลือก และตรวจความครอบคลุมของคลัง ปิดตัวบังคับกฎได้ในหน้า "กฎตัดสินใจ" เพื่อดูผลเดิมที่ตรงกับ Excel
- `learn.js` บันทึกผลรายมาตรการ รอบประเมินซ้ำ รายงานไม่ระบุชื่อ และกฎเสนอปรับคลัง L1–L7 (ไม่ปรับคลังอัตโนมัติ)
- `evalkit.js` แบบประเมินผู้เชี่ยวชาญ (กรณีจำลอง 27 กรณี + 15 ข้อ) แบบประเมินผู้บริหาร (4 ด้าน + SUS) ตัววิเคราะห์ และตารางตัวชี้วัดความสำเร็จ `stats.js` สถิติ (ตรวจเทียบ scipy)
- `tool2.js`/`tool2.css` หน้าจอ: กฎตัดสินใจและเหตุผล · ติดตามผลและบทเรียน · ประเมินนวัตกรรม · ห้องวิเคราะห์ของผู้วิจัย
- ทุกกฎ เกณฑ์ และข้อคำถามเป็นร่างของผู้วิจัย ยังไม่ผ่านเดลฟาย IOC หรือการรับรองจริยธรรม ไม่มีผลวิจัยในเว็บ ถ้าไม่มีข้อมูลตารางตัวชี้วัดแสดง "ยังไม่มีข้อมูล"
- `examples/` คือไฟล์สมมติ (synthetic) สำหรับทดสอบห้องวิเคราะห์เท่านั้น สร้างด้วย `node tools/make_examples.js` เว็บแสดงแถบเตือนเมื่อนำเข้า
- ข้อมูลที่ผู้ใช้กรอกอยู่ในเบราว์เซอร์ ส่งออกเป็นไฟล์ในเครื่องเมื่อผู้ใช้สั่งเท่านั้น รายงานส่งผู้วิจัยไม่มีชื่อโรงเรียนและข้อความอิสระโดยปริยาย

ทดสอบ: `node tests/test_engine.js && node tests/test_bankloader.js && node tests/test_decision.js && node tests/test_stats.js && node tests/test_learn.js && node tests/test_eval.js && node tests/test_examples.js`
